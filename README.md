# Code and Data Availability

This repository contains the MATLAB and R code used for the computational analyses presented in our study.

## MATLAB Code

The MATLAB scripts are provided for the following analyses:

1. **Synthetic Data Generation:** Generation of synthetic mRNA expression datasets using the Stochastic Simulation Algorithm (SSA).
2. **mRNA Distribution Computation:** Numerical computation of mRNA probability distributions using the Finite State Projection (FSP) method.
3. **Parameter Inference:** Model fitting and kinetic parameter estimation using Maximum Likelihood Estimation (MLE).
4. **Model Selection:** Statistical comparison of competing transcriptional regulatory models using the corrected Akaike Information Criterion (AICc).

## R Code

The R scripts are provided for the following analyses:

1. **Pseudotime Reconstruction:** Reconstruction of transcriptional trajectories using single-cell transcriptomic data.
2. **Functional Enrichment Analysis:** Gene Ontology (GO) and KEGG pathway enrichment analyses.
3. **Core Promoter Motif Analysis:** Quantification of core promoter motifs.
4. **Promoter Width Analysis:** Characterization of promoter width distributions.
5. **H3K4me3 Analysis:** Quantification of transcription start site (TSS)-associated H3K4me3-marked chromatin width.
6. **Enhancer–Promoter Interaction Analysis:** Quantification of enhancer–promoter interaction strength.

## Reproducibility

The provided scripts support the computational analyses and figure generation described in the manuscript.
